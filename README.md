Goal:
Predict whether a bank customer will churn(leave the bank) or not
Output: 0 (No churn) / 1 (Churn)
Type: Binary classification problem 


Project architecture:
1. Dataset
2. EDA + Preprocessing
3. Model traning
4. Hyperparameter tuning
5. Save the model
6. Predict the output/Streamlit app

Important notes:
1. In Python, import pickle gives you access to the pickle module, which is used for serializing and deserializing objects. Basically in our code, the model, encodings, scalings will be saved in pickle file format
